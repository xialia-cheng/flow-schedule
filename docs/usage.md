# 微澜日程功能与实况通知

[返回微澜日程项目主页](https://github.com/xialia-cheng/ripple-plan)

## 下载

打开 **[GitHub 最新发布](https://github.com/xialia-cheng/ripple-plan/releases/latest)**，在 **Assets** 中下载 `app-release.apk`。应用支持 **Android 7.0（API 24）及以上版本**。

## 课表与作息

- 在「课表」切换周视图和日视图。周视图适合看一周的课程，日视图会把当天课程和日程放在一起。
- 在「课表控制中心」新建或切换课表，设定开学日、学期周数和每周起始日。总周数可设为 1–52 周，节次作息支持 6–16 节，可逐节调整或批量生成。
- 在「编辑课表」添加课程并填写教室、教师和备注。周次支持全周、单双周，也可点选不连续的周次，例如第 5–10 周和第 12–18 周。课程颜色可从预设中选择或自定义。
- 可调整课表行高、字号、周末列和非本周课程的显示。需要时可开启打卡条和课间分隔条，并在「今日进度」查看已上、进行中及待上的课程。

## 导入与分享课表

- 点课表页右上角的「导入」，选择本地 CSV 文件、粘贴 Excel 表格文本，或导入教务系统导出的 HTML 课表表格。CSV 导入也支持 WakeUp 课表导出格式。
- CSV 和 HTML 可追加到当前课表，也可选择覆盖当前课表的课程。导入后可核对课程、节次与周次。
- 点右上角「分享课表」生成口令。接收方可以把口令导入为独立的新课表，也可把其中的课程加入当前课表。

## 日程与一句话创建

- 在「日程」按今天、明天、未来、全部或选定日期查看安排。待办按时段或日期分组，已完成项单独展示。
- 手动创建日程时可设置标签、起止时间、提前提醒和重复规则。提醒可按每日、工作日或每周重复，日程也可标记完成或稍后 10 分钟提醒。
- 点「一句话智能创建」，例如输入「明天下午2点半在教A-301上数据结构 提前15分钟 免打扰」。先在草稿中核对时间、地点和提醒，再确认保存。与已保存的日程或当前课表时间重叠时，应用会在草稿上提示冲突。
- 默认用本地规则解析中文。需要时可在「我的」配置兼容 OpenAI 接口的 HTTPS 服务，服务不可用时应用会尝试回到本地解析。[查看自定义 AI 的数据发送范围](https://github.com/xialia-cheng/ripple-plan/blob/main/docs/privacy.md)

## 专注学习与桌面小组件

- 在「学习」自定义专注名称、专注和休息时长。专注时长支持 1–180 分钟，休息时长支持 0–60 分钟。计时可暂停或重置，完成的专注会计入累计时长。
- 学习任务可以关联课程、记录预计时长并勾选完成。专注计时可联动实况通知及系统勿扰模式，使用勿扰联动需要允许应用控制勿扰。
- 在系统桌面的组件列表添加「微澜日程 · 下一项」，可查看今天正在进行或即将开始的课程与日程。较大的组件还会显示后续安排。

## 实况通知与提醒

课程可设置课前提醒，日程可分别指定提前提醒时间。应用在兼容设备上通过 Android 16 Live Updates 显示上课、日程或专注倒计时，包括支持该能力的 ColorOS 流体云。系统未提供实况胶囊时，应用使用通知栏进度提醒。

可在「我的」查看通知和精确闹钟权限诊断，并控制锁屏是否显示教室、教师和备注。后台守护默认关闭，可按需开启。提醒能否准时送达仍取决于系统权限、设备设置和后台策略。

## 外观与本地备份

- 在「我的」切换浅色、深色或跟随系统主题。Android 12 及以上可选择随系统壁纸取色，应用内触觉反馈也可开关。
- 在「我的」或课表的导入导出入口保存 JSON。备份包含课表、课程、节次时间和日程（含已完成）。恢复时可选择智能合并，或用备份覆盖当前课表和日程。JSON 内含教室、教师及日程备注等明文信息，请妥善保管。
