## 下载

打开 **[GitHub 最新发布](https://github.com/xialia-cheng/ripple-plan/releases/latest)**，在 **Assets** 中下载 `app-release.apk`。应用支持 **Android 7.0（API 24）及以上版本**。

如果系统将「微澜日程」和旧版「流云日程」识别为两个应用，请先在旧版导出 JSON 备份，再在新版导入并核对恢复结果。

## 功能

管理多份课表和单双周课程，用一句中文添加日程，或为常用待办设置重复提醒。应用还提供专注计时、桌面小组件和 JSON 备份。兼容设备可使用 Android 实况通知和 ColorOS 流体云。

[查看功能、使用方法与实况通知兼容性](https://github.com/xialia-cheng/ripple-plan/blob/main/docs/usage.md)

## 隐私与联网

核心功能离线可用。版本检查可关闭，自定义 AI 解析默认关闭。

[查看数据存储、联网用途与备份说明](https://github.com/xialia-cheng/ripple-plan/blob/main/docs/privacy.md)

## 从源码构建

源码构建需要 JDK 21、Gradle 9.3.1 和 Android SDK 36.1。

[查看构建、单元测试和 lint 命令](https://github.com/xialia-cheng/ripple-plan/blob/main/docs/build.md)
