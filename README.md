## 下载

打开 **[GitHub 最新发布](https://github.com/xialia-cheng/ripple-plan/releases/latest)**，在 **Assets** 中下载 `app-release.apk`。应用支持 **Android 7.0（API 24）及以上版本**。

## 功能

- **课表与作息**　支持多课表、周视图和日视图，可设置开学日、1–52 周学期和 6–16 节作息。课程支持单双周、任意组合周次、自定义配色与教室信息。浏览和编辑可切换，查看时更不容易误触。
- **导入与分享**　可从 CSV、Excel 粘贴的表格文本或教务系统导出的 HTML 表格导入课表，也可用分享口令导入一份独立课表。
- **日程与提醒**　按今天、明天、未来或指定日期查看待办。可设置提前提醒、自定义标签和每日、工作日或每周重复。
- **一句话创建**　用中文录入课程或日程，先预览和调整草稿，再确认保存。应用会检查和已有课表、日程的时间冲突，默认在设备上解析。
- **专注学习**　自定义专注和休息时长，记录累计专注时间。学习任务可关联课程、填写预计时长和标记完成。
- **实况通知与小组件**　在兼容设备上查看 Android 实况通知或 ColorOS 流体云倒计时，其余设备可使用通知栏进度提醒。桌面小组件展示今天下一项课程或日程。
- **外观与本地备份**　支持浅色、深色、跟随系统和 Android 12+ 壁纸取色。课表、节次和日程可导出为 JSON，恢复时可选择合并或覆盖。

[查看详细功能、操作入口与通知兼容性](https://github.com/xialia-cheng/ripple-plan/blob/main/docs/usage.md)
